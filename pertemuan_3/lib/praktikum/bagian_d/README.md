# Praktikum D – To-Do List

## Tujuan
Memahami cara membuat daftar tugas interaktif menggunakan Flutter.

## Penjelasan
Aplikasi memungkinkan pengguna menambahkan tugas, menandai tugas yang selesai, menghapus tugas, dan membersihkan tugas yang telah selesai.

## Komponen yang Digunakan
- `TextField` untuk memasukkan tugas.
- `ListView` untuk menampilkan daftar tugas.
- `Checkbox` untuk menandai tugas selesai.
- `IconButton` untuk menghapus tugas.
- `setState()` untuk memperbarui daftar.

## Kesimpulan
Praktikum ini membantu memahami pengelolaan daftar data dan interaksi pengguna pada aplikasi Flutter.

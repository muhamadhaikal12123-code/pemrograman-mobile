# Praktikum A – Input Dasar

## Tujuan
Memahami penggunaan input dan pengolahan teks pada Flutter.

## Penjelasan
Pada praktikum ini, pengguna dapat memasukkan nama melalui TextField. Setelah tombol ditekan, aplikasi menampilkan sapaan berdasarkan nama yang dimasukkan.

## Komponen yang Digunakan
- `TextField` untuk memasukkan nama.
- `TextEditingController` untuk mengambil input.
- `ElevatedButton` untuk menjalankan aksi.
- `setState()` untuk memperbarui tampilan.

## Kesimpulan
Praktikum ini membantu memahami cara menerima input pengguna dan menampilkan hasilnya di aplikasi Flutter.

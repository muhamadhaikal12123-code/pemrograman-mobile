# Praktikum B – Form Validation

## Tujuan
Memahami cara membuat formulir dan melakukan validasi input pada Flutter.

## Penjelasan
Form digunakan untuk menerima data dari pengguna. Validasi dilakukan untuk memastikan data yang dimasukkan sesuai dengan ketentuan sebelum diproses.

## Komponen yang Digunakan
- `Form` untuk membungkus formulir.
- `TextFormField` untuk menerima input.
- `GlobalKey<FormState>` untuk menjalankan validasi.
- `DropdownButtonFormField` untuk memilih kategori.
- `Checkbox` untuk persetujuan.
- `SnackBar` untuk menampilkan pesan.

## Kesimpulan
Praktikum ini membantu memahami pembuatan formulir, validasi data, dan pemberian pesan kepada pengguna.

# Praktikum C – State Management

## Tujuan
Memahami pengelolaan state pada aplikasi Flutter.

## Penjelasan
Aplikasi menggunakan variabel untuk menyimpan nilai penghitung. Nilai dapat ditambah, dikurangi, dan dikembalikan ke nilai awal. `setState()` digunakan agar tampilan berubah ketika nilai diperbarui.

## Komponen yang Digunakan
- `StatefulWidget` untuk halaman yang memiliki state.
- `setState()` untuk memperbarui tampilan.
- `ElevatedButton` untuk menjalankan aksi.
- Variabel integer untuk menyimpan nilai penghitung.

## Kesimpulan
Praktikum ini menjelaskan bagaimana perubahan data dapat ditampilkan secara langsung pada antarmuka Flutter.

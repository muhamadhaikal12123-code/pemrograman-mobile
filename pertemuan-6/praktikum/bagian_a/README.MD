## Deskripsi
Bagian A membahas penerapan tema pada aplikasi Flutter, termasuk tema terang, tema gelap, dan penggunaan warna tema.

## Tujuan
- Memahami pengaturan tema aplikasi.
- Menggunakan `ThemeData`.
- Memahami penggunaan `Theme.of(context)`.

## Cara Menjalankan
Salin file `main.dart` ke folder `lib`, lalu jalankan aplikasi menggunakan Flutter.

```powershell
Copy-Item .\praktikum\bagian_a\main.dart .\lib\main.dart -Force
flutter run -d chrome
```

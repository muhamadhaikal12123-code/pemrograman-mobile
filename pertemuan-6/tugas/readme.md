## Deskripsi
Tugas Mandiri merupakan aplikasi katalog produk sederhana yang dibuat menggunakan Flutter. Aplikasi ini menerapkan tema, navigasi, dan animasi.

## Fitur
- Katalog produk.
- Detail produk.
- Keranjang simulasi.
- Animasi dan transisi halaman.
- Tema terang dan gelap.
- Pilihan warna tema.
- Penyimpanan pengaturan tema menggunakan `shared_preferences`.

## Cara Menjalankan

```powershell
flutter pub get
Copy-Item .\tugas\main.dart .\lib\main.dart -Force
flutter run -d chrome
```

## Pemeriksaan Kode

```powershell
flutter analyze
```

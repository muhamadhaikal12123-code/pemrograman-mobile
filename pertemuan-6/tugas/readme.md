# Tugas Pertemuan 6 — Katalog Wisata Nusantara

Katalog interaktif dengan 3 tab (`Katalog`, `Animasi`, `Pengaturan`), named routes `/detail` + `Hero`, animasi implisit (`AnimatedContainer`) & eksplisit (`AnimationController`), serta pengaturan mode terang/gelap dan 4 pilihan warna berbasis `Theme.of(context)`.

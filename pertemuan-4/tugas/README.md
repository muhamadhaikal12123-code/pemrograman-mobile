# Tugas — Aplikasi Daftar Postingan

Aplikasi ini mengambil data postingan dari JSONPlaceholder. Pengguna dapat melihat daftar postingan, membuka detail postingan, dan membaca komentar dari API.

## Menjalankan
1. Salin kode `main.dart` ke project Flutter.
2. Jalankan `flutter pub add http`.
3. Pastikan izin internet Android tersedia.
4. Jalankan aplikasi dengan `flutter run`.

# Pertemuan 4 — Mengambil Data dari REST API

## Deskripsi
Pada pertemuan ini, saya mempelajari cara mengambil data dari internet menggunakan REST API di Flutter. Data yang diterima dari server kemudian diolah dan ditampilkan ke dalam aplikasi.

Materi ini membahas penggunaan `Future`, `async/await`, paket `http`, JSON, dan `FutureBuilder`. Saya juga belajar menampilkan indikator loading saat data sedang dimuat serta menangani error ketika permintaan data gagal.

## Materi Praktikum
- Bagian A — Future dan FutureBuilder.
- Bagian B — Menyiapkan paket HTTP.
- Bagian C — Mengubah JSON menjadi model Dart dan mengambil data API.
- Bagian D — Menampilkan daftar data dari API dengan kondisi loading dan error.
- Bagian E — Menampilkan halaman detail data.
- Bagian F — Mencoba dan menangani error API.

## Tugas
Membuat aplikasi Daftar Postingan yang mengambil data dari REST API. Aplikasi menampilkan daftar postingan, isi lengkap postingan, dan komentar yang berhubungan dengan postingan tersebut.

## Kesimpulan
Melalui praktikum ini, saya belajar mengambil data dari API, mengolah respons JSON, dan menampilkan data secara asynchronous di Flutter.

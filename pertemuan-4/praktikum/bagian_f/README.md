# Bagian F — Penanganan Error

Coba lakukan percobaan berikut:
1. Ubah URL API menjadi `https://jsonplaceholder.typicode.com/userz` untuk mencoba respons endpoint yang tidak tersedia.
2. Jalankan aplikasi saat koneksi internet terputus.
3. Perhatikan pesan error yang ditampilkan.
4. Kembalikan URL ke endpoint yang benar dan tekan tombol muat ulang.

Catat hasil percobaan dan jelaskan kenapa aplikasi perlu menampilkan pesan error.

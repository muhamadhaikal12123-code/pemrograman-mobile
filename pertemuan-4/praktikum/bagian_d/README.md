# Bagian D — Menampilkan Data dengan FutureBuilder

Bagian ini menampilkan daftar pengguna dari API. Halaman punya tiga kondisi: loading saat data dimuat, pesan error dengan tombol coba lagi jika gagal, dan daftar pengguna jika berhasil. Tombol refresh di AppBar juga dapat digunakan untuk memuat ulang data.

Jalankan `flutter pub add http` sebelum mencoba kode.

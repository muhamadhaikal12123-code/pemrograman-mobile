# Bagian A — SharedPreferences

Contoh `main.dart` menyimpan nama, mode gelap, dan jumlah aplikasi dibuka menggunakan `shared_preferences`.

Jalankan di proyek Flutter:
```bash
flutter pub add shared_preferences
```
Salin `main.dart` ke `lib/main.dart`, lalu jalankan di emulator Android. Hentikan aplikasi sepenuhnya dan buka lagi untuk mengecek data tetap tersimpan.

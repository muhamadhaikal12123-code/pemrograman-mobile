# Bagian B — Menyiapkan SQLite

Pasang paket:
```bash
flutter pub add sqflite path
```

`main.dart` berisi model `Catatan` dan `DbHelper` untuk membuat tabel serta operasi tambah, baca, ubah, dan hapus. Bagian ini adalah fondasi database; jalankan bersama UI dari bagian C–D atau gunakan aplikasi tugas sebagai contoh lengkap.

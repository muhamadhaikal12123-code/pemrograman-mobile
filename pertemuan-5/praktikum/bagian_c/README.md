# Bagian C — Daftar Catatan (Read dan Delete)

Bagian ini melengkapi Bagian B dengan UI daftar catatan. Kode `main.dart` dapat dipakai sebagai aplikasi mandiri, bersama helper SQLite dan form pada bagian D yang sudah digabung agar mudah dicoba.

Pasang paket:
```bash
flutter pub add sqflite path
```
Checkpoint: daftar menampilkan catatan tersimpan dan ikon hapus meminta konfirmasi.

## Deskripsi
Aplikasi Daftar Kontak dibuat menggunakan Flutter untuk menerapkan model data, ListView, dan navigasi antarhalaman.

## Ketentuan Tugas
1. Menampilkan minimal 6 kontak.
2. Setiap kontak memiliki nama, nomor telepon, dan email.
3. Halaman utama menggunakan ListView.builder dan ListTile.
4. Avatar menampilkan huruf pertama nama kontak.
5. Menekan kontak membuka halaman detail.
6. Halaman detail menampilkan seluruh data kontak dan tombol kembali.

## Konsep yang Digunakan
- Class Dart
- List data objek kontak
- ListView.builder
- ListTile dan CircleAvatar
- Navigator.push
- Navigator.pop

## File Program
`daftar_kontak.dart`

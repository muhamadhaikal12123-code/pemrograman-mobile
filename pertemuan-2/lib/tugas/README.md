## Deskripsi
Membuat aplikasi daftar kontak menggunakan Flutter. Aplikasi menampilkan daftar kontak dan menyediakan halaman detail untuk melihat informasi setiap kontak.

## Fitur
- Menampilkan minimal 6 kontak.
- Menampilkan nama dan nomor telepon.
- Menggunakan avatar dengan huruf pertama nama.
- Menampilkan detail nama, nomor telepon, dan email.
- Navigasi ke halaman detail menggunakan `Navigator.push`.
- Kembali ke halaman sebelumnya menggunakan `Navigator.pop`.

## Widget yang Digunakan
- `ListView.builder`
- `ListTile`
- `CircleAvatar`
- `Card`
- `Navigator.push`
- `Navigator.pop`

## File Program
`daftar_kontak.dart`

## Cara Menjalankan
1. Buka terminal di folder proyek.
2. Jalankan `flutter run`.
3. Pilih menu **Tugas - Daftar Kontak**.
4. Tekan salah satu kontak untuk melihat detailnya.

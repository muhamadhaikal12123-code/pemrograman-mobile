# Pertemuan 1 — Pengenalan Flutter

## Deskripsi

Pada pertemuan pertama ini, saya mulai mempelajari Flutter sebagai framework untuk membuat aplikasi mobile menggunakan bahasa pemrograman Dart. Materi dimulai dari pengenalan Flutter, struktur project, sampai membuat tampilan aplikasi sederhana.

Praktikum ini juga membantu saya memahami cara kerja widget dan bagaimana tampilan aplikasi disusun di dalam Flutter.

## Materi yang Dipelajari

- Pengenalan Flutter dan kegunaannya untuk pengembangan aplikasi.
- Mengenal struktur folder dan file dalam project Flutter.
- Memahami fungsi `MaterialApp`, `Scaffold`, `AppBar`, `Text`, dan widget dasar lainnya.
- Mengatur tampilan aplikasi menggunakan widget layout.
- Memahami perbedaan `StatelessWidget` dan `StatefulWidget`.
- Membuat aplikasi counter sederhana menggunakan `setState()`.

## Praktikum

Praktikum dibagi menjadi beberapa bagian untuk mencoba penggunaan widget dan pengelolaan state secara langsung.

### Bagian A — Pengenalan Flutter
Membuat aplikasi pertama dengan tampilan sederhana, termasuk AppBar dan teks pada halaman utama.

### Bagian B — Widget dan Layout
Mencoba beberapa widget dasar untuk menyusun elemen pada layar agar tampilan aplikasi lebih teratur.

### Bagian C — StatefulWidget
Mempelajari perubahan tampilan berdasarkan state yang dimiliki aplikasi.

### Bagian D — Counter
Membuat aplikasi penghitung angka dengan fitur menambah angka, mengurangi angka, dan mengembalikan angka ke nilai awal. Pada latihan ini, pengurangan juga dibatasi agar angka tidak menjadi negatif.

## Tujuan Praktikum

Setelah menyelesaikan praktikum ini, saya diharapkan memahami dasar pembuatan aplikasi Flutter, mengenal widget yang sering digunakan, serta bisa membuat tampilan dan interaksi sederhana.

## Struktur Folder

- `praktikum/` — Berisi kode latihan dari setiap bagian praktikum.
- `tugas/` — Berisi kode untuk tugas pertemuan pertama.
- `doc-tugas/` — Tempat menyimpan dokumentasi atau laporan tugas.
- `README.md` — Penjelasan mengenai materi dan isi folder pertemuan ini.

## Kesimpulan

Dari praktikum pertama, saya mulai memahami cara membuat aplikasi menggunakan Flutter, menyusun tampilan dengan widget, dan mengubah data yang ditampilkan menggunakan state. Materi ini menjadi dasar untuk praktikum selanjutnya.

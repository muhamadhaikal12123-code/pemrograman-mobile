# Bagian E - Layout

## Tujuan

Membuat tampilan yang berisi icon, nama, dan NIM yang tersusun secara vertikal di tengah halaman.

## Langkah

1. Mengubah bagian `body` pada aplikasi.
2. Menggunakan `Center` untuk menempatkan tampilan di tengah.
3. Menggunakan `Column` untuk menyusun widget secara vertikal.
4. Menambahkan icon Flutter.
5. Menambahkan nama dan NIM.
6. Menjalankan aplikasi pada Android Emulator.

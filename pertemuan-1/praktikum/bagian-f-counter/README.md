# Bagian F - StatefulWidget dan Counter

## Tujuan

Membuat aplikasi counter menggunakan `StatefulWidget` dan `setState()`.

## Langkah

1. Membuat `CounterPage` menggunakan `StatefulWidget`.
2. Membuat `_CounterPageState` sebagai state.
3. Membuat variabel `_count` dengan nilai awal `0`.
4. Menampilkan nilai counter menggunakan `Text`.
5. Menambahkan `FloatingActionButton`.
6. Menggunakan `setState()` untuk menambah nilai counter.
7. Menjalankan aplikasi pada Android Emulator.

## Hasil

Aplikasi menampilkan angka counter di tengah halaman dan tombol `+` di kanan bawah.

Ketika tombol `+` ditekan, angka bertambah:

`0 → 1 → 2 → 3 → ...`

## Kesimpulan

Pada bagian ini dipelajari penggunaan `StatefulWidget`, `State`, dan `setState()` untuk mengubah tampilan aplikasi berdasarkan perubahan data.

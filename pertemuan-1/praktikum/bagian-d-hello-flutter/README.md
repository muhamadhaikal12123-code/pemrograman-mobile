# Bagian D - Hello Flutter

## Tujuan

Membuat aplikasi sederhana yang menampilkan tulisan menggunakan widget Flutter.

## Langkah

1. Membuka file `lib/main.dart`.
2. Mengubah tampilan aplikasi menggunakan `MaterialApp`.
3. Menambahkan `AppBar` dengan judul `Hello Flutter`.
4. Menggunakan `Center` untuk menempatkan teks di tengah.
5. Menggunakan widget `Text` untuk menampilkan nama.
6. Menjalankan aplikasi pada Android Emulator.
7. Mengamati perubahan menggunakan Hot Reload.

## Hasil

Aplikasi menampilkan:

**Halo, nama saya Muhamad Haikal Umardi!**

Teks ditampilkan di bagian tengah halaman.

## Kesimpulan

Pada bagian ini dipelajari penggunaan `MaterialApp`, `Scaffold`, `AppBar`, `Center`, dan `Text`.

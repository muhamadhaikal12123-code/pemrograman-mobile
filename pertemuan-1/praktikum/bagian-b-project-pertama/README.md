# Bagian B - Project Flutter Pertama

## Tujuan

Membuat dan menjalankan project Flutter pertama menggunakan Flutter SDK.

## Langkah

1. Membuat project Flutter dengan nama `praktikum_1`.
2. Membuka folder project menggunakan editor.
3. Menjalankan aplikasi Flutter pada Android Emulator.
4. Mengamati aplikasi bawaan Flutter yang tampil pada emulator.

## Hasil

Project Flutter berhasil dibuat dan dapat dijalankan pada Android Emulator.

Aplikasi menampilkan halaman Flutter dengan counter dan tombol tambah.

## Kesimpulan

Pada bagian ini berhasil dibuat project Flutter pertama dan menjalankannya pada Android Emulator.

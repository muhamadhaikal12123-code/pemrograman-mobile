# Bagian C - Struktur Project

## Tujuan

Memahami struktur folder dan file yang terdapat pada project Flutter.

## Struktur Project

Beberapa bagian penting dalam project Flutter:

* `lib/main.dart` → file utama untuk menjalankan aplikasi.
* `pubspec.yaml` → berisi konfigurasi project dan dependencies.
* `android/` → bagian project untuk Android.
* `ios/` → bagian project untuk iOS.
* `web/` → bagian project untuk Web.
* `windows/` → bagian project untuk Windows.
* `linux/` → bagian project untuk Linux.
* `macos/` → bagian project untuk macOS.

## Hasil

Project Flutter memiliki beberapa folder dan file yang digunakan untuk menjalankan serta mengatur aplikasi.

## Kesimpulan

Pada bagian ini dipelajari struktur dasar project Flutter dan fungsi dari beberapa file serta folder penting di dalamnya.

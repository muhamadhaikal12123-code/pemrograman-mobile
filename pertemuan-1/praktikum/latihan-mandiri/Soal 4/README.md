# Soal 4 - Mencegah Angka Negatif

## Tujuan

Mencegah nilai counter menjadi angka negatif.

## Hasil

Tombol `-` hanya dapat mengurangi angka jika nilai counter lebih dari `0`.

Jika nilai sudah `0`, tombol `-` tidak akan membuat angka menjadi negatif.

## Kesimpulan

Pada latihan ini digunakan kondisi `if` untuk membatasi nilai counter agar tidak kurang dari `0`.

# Soal 2 - Menambahkan Tombol Minus

## Tujuan

Menambahkan tombol `-` untuk mengurangi nilai counter.

## Hasil

Aplikasi memiliki dua tombol:

* `+` untuk menambah angka.
* `-` untuk mengurangi angka.

## Kesimpulan

Pada latihan ini dipelajari cara menambahkan tombol dan membuat nilai counter dapat bertambah maupun berkurang.

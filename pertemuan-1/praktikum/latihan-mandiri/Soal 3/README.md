# Soal 3 - Tombol Reset

## Tujuan

Menambahkan tombol reset untuk mengembalikan nilai counter menjadi `0`.

## Hasil

Aplikasi memiliki tiga tombol:

* `-` untuk mengurangi angka.
* Reset untuk mengembalikan angka menjadi `0`.
* `+` untuk menambah angka.

## Kesimpulan

Pada latihan ini dipelajari cara membuat fungsi reset menggunakan `setState()`.

# Bagian A - Instalasi dan Verifikasi

## Tujuan

Melakukan instalasi dan pengecekan Flutter, Android Studio, Android SDK, emulator, serta extension Flutter dan Dart.

## Langkah

1. Menginstal Flutter SDK.
2. Menginstal Android Studio.
3. Mengatur Android SDK.
4. Membuat Android Emulator.
5. Menginstal extension Flutter dan Dart pada editor.
6. Menjalankan perintah `flutter doctor`.
7. Memastikan Flutter dan Android toolchain dapat digunakan.

## Hasil

Flutter berhasil terinstal dan dapat digunakan untuk membuat serta menjalankan aplikasi Flutter.

Android Emulator juga berhasil digunakan sebagai perangkat untuk menjalankan aplikasi.

## Kesimpulan

Pada bagian ini dilakukan persiapan lingkungan kerja sebelum membuat aplikasi Flutter.

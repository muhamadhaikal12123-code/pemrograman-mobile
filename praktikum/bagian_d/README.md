# Bagian D — Form Tambah dan Ubah Catatan

Contoh mandiri pada `main.dart` menggabungkan CRUD SQLite: tambah, daftar, ubah, hapus dengan dialog konfirmasi. Ini mencakup materi Bagian B–D agar dapat langsung dijalankan.

Pasang:
```bash
flutter pub add sqflite path
```
Jalankan di emulator Android/iOS, lalu tutup aplikasi sepenuhnya dan buka kembali untuk menguji data tetap tersimpan.
